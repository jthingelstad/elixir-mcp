# The collector example says the Family tier

The worked example for the collector fleet, and a collector's own page in the console, now say what running a collector earns: the Family tier while it is active, and nothing else. The example no longer mentions points, call credits or bonus slots, and the collector page's "tier" line now reads "earns", noting that a granted tier above Family stands. MCP 11.11.3 and JSON API 3.2.0 unchanged.
