# The docs agree with the code, third pass

A last read of the guides people lean on most, and the word for what your account is.

The docs now say **role** where they said tier, the same word Settings uses, so Roles is the page's name in the docs menu. Its address has not changed. The Why fifty players section has a new heading, so an old link to that section opens the top of the page.

The inactivity clock page now lists every case where the clock waits, what the morning email says about a removal, and that a waiting period also counts as protected. Battles and Reading the numbers now say that the seasonal Trophy Road past 14,000 moves trophies too, and which battles have no `rounds[]` or `duration`.

For people building on Elixir: `elixir_docs` with no page carries no `applied`, `cards_catalog` serves only `forms_available`, and `finished_early` is `null` while a week is being fought.

MCP and JSON API unchanged.
