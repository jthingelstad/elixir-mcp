# Elixir is for members

Reading Elixir needs a free account: players, clans, timelines and
profiles, on the website, over MCP and through the JSON API. A battle link
someone sends you still opens without one, with its preview, and so do
the game's card list, this site and its docs, and signing in. The sign-in
screen now says so, and the privacy page lists what opens without an
account.

MCP and JSON API unchanged.
