# Share a session

A session's page now has **Share this session**, so you can send a great run to a friend or a group chat.

- **Copy link** copies the session's own link. Anyone can open it, no account needed: the headline, the figures, the decks and every battle, with players by their game names.
- **Share image** saves a picture of the session, with its deck's art.
- **Copy for a post** copies one short line with the link.

Links you already got in email, Discord, notifications or RSS now open for friends without an account too. A link works for 30 days.

Also: the setup list on your Timeline is now called **Getting set up**, a long session counts each deck across all its battles, and Settings › Comments & blocks has its own name in your browser tab.

MCP and JSON API unchanged.
