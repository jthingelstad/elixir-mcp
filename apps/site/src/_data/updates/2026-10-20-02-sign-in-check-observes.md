# The sign-in check goes back to recording

The sign-in check that started deciding earlier today is back to only
recording. Another service built the same way found real people whose
browsers sent no check at all, and Elixir's few sign-ins so far cannot
show that will not happen here. Every sign-in email is sent again,
whatever the check says, while we learn why a check can be missing.
Nobody was turned away while it was deciding.

[Limits](/docs/limits) has the current rule.

MCP 11.13.1 and JSON API 3.2.0, unchanged.
