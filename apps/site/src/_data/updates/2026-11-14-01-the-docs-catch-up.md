# The docs catch up

A few help pages still talked about Elixir before the redesign. They
now say what it does today:

- [Stats](/docs/ladder) is just Stats, with no old name.
- [Sign in with Elixir](/docs/sign-in-with-elixir) says what Elixir
  Drop asks for: to read recorded game data and to know your email
  address. It never asks to change who you follow.
- [Users and agents](/docs/connections) says Home opens on its welcome
  steps, and that your digest in Settings › Emails is Weekly, Daily or
  Off.

MCP and JSON API unchanged.
