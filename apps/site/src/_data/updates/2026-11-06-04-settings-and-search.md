# Settings has its own home, and search opens where you are

Everything about your account now lives at Settings, with one rail: Profile, Players and tracking, Emails, Connections and agents, Sign-ins and devices, Usage and limits, and Feedback. Old links keep working, including the ones in mail you already have.

An agent is a page there now, not a place you switch into. New agent opens in place, and an agent has five tabs: Overview, What it reads, Usage, Connections and Settings. Sharing your timeline to Discord has its own page under Connections.

The magnifier on the top bar opens a search sheet: your players and clans as you type, your clan's roster, and any tag on record. Following a tag from there asks first, as Home does. The question mark opens help for the page you are on, a link to read more, and a way to send feedback with the page attached. Actions that are hard to undo, such as disconnecting an app or revoking a key, now always ask first.

MCP 11.17.1, JSON API 3.3.0 unchanged.
