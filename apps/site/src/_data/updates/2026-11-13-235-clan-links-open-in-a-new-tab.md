# Clan's links open in a new tab when you ask

Cmd-click, Ctrl-click or middle-click on a link in Clan (an action card,
your record, the season, a member, Run's settings) now opens it in a new
tab, as links do everywhere else in Elixir. Before, Clan caught those
clicks and opened the page in the same tab. A plain click works as it
did, and the links look the same.

MCP and JSON API unchanged.
