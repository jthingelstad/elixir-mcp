# A sitting says which trophies it moved

A sitting on the timeline (`battle_session` and `session_standout`) now
carries `trophy_net_by_mode`: the net of each mode whose battles move
trophies, Trophy Road, Path of Legends and the seasonal Trophy Road past
14,000. `trophy_net` is still Trophy Road's alone, so a Path of Legends
sitting that showed 0 there, while `battles_performance` showed +180 for
the same battles, now says where the 180 came from
([Timeline](/docs/timeline)).

MCP 11.15.0 (an addition). JSON API unchanged.
