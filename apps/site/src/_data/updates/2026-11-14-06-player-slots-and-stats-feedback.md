# Player slots on Roles, and feedback about Stats says Stats

The Roles page's first quota row now reads "Player slots (a free follow
uses none)", the same slots Settings counts as Player slots used. A
player you follow for free never spends one.

Feedback you send about Stats is labelled Stats, in the answer email
and on the maintainer's list, where it still said Ladder.

MCP 13.1.1 and JSON API 5.1.0 unchanged.
