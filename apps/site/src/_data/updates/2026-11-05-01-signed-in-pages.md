# The public pages know you are signed in

The home page and the docs no longer offer Sign in or Create your account to someone who is already signed in: the top bar shows your player, and the home page offers Open Elixir. The clan map no longer reports an error each time it opens. New agent now opens its form right there on Connections, and you stay on the page.

MCP 11.15.0 and JSON API 3.3.0, unchanged.
