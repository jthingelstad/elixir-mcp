# Old addresses stopped working

Addresses from before the redesign no longer send you on to the new page.
That covers the old Console (`/console/...`), Ladder (`/ladder/...`), Home's
old Timeline and Friends tabs, Clan's old tabs (Today, Season, Awards,
Manage and the rest), and links to sections of the docs that moved when a
long page split. Following one now shows the missing page.

Every link Elixir sends today goes straight to its page: the digest,
collector mail, Clan's Actions mail and Discord posts, sign-in and
unsubscribe links, shared posts and battles, and your RSS feed. A clan's
own address, `/clan/<tag>`, and its Actions list still open the clan's
Feed.

`elixir_docs` no longer answers an old `page` and `section` pair that
moved; ask for the section on its current page.
