# Your page looks like Home

You and every player's page now look like Home: the name, tag and counts
sit right on the page instead of in a box, and on your phone the picture
sits beside the name, so the timeline starts on the first screen.

- Times read the way Home says them: "Today, 3:37 pm" and day heads like
  "Today".
- A session opens with the same button as on Home, Open session.
- Moments and Highlights sit on the page like Home's cards, and an empty
  tab is one quiet line.
- Stats' tables use the same numbers as the rest of Elixir.

What each page shows, and who can see it, is the same.

MCP and JSON API unchanged.
