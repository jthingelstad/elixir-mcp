# Clearer phone controls and quieter pages

The site and Docs now carry the app’s gold verified-player state in their
signed-in header. If no recent player state is available, the header uses
a generic account icon.

The front page brings its promise and sign-in choices closer to the top.
Docs groups its next steps in flatter rows, with roomier links and a
clear focus outline on search.

Phone fields are easier to read, the clan member search fills the screen’s
content width, and Stats and Settings use more consistent spacing. Shorter
transitions keep the interface responsive to your taps; reduced motion is
still respected.

MCP 13.1.1 and JSON API 5.1.0 unchanged.
