# Only people's tracking keeps a recording going

Elixir records a player or clan because someone tracks it, and now for no other reason. The maintainer used to have a reason of their own that kept a recording going after everyone had stopped tracking it; that reason is retired, and the maintainer tracks from an account like anyone else. A recording that only it kept going now stops like any other, and stopping a recording deletes nothing. If you track a player or clan, nothing changes for you. MCP 11.11.2 and JSON API 3.2.0 unchanged.
