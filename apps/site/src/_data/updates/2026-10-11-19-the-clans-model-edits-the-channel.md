# A clan's own model edits its Discord channel

With the clan's own model key and the leaders' voice set, a clan's activity channel (Elixir Clan's Social ▸ Discord) is now edited by the clan's model rather than rewritten line by line. A few minutes after the activity lands, the model is handed the stories Elixir built, with what Elixir knows about each. It may look things up in the clan's record first, read-only: a member's record, a member's battles this week, what the channel said in the last three days. Then it decides what is worth a post: it can tell several stories in one post, and skip one with a short reason the page lists. Every post is checked before it is sent: the names it was given, no number or name it did not read, no time of day, no link or mention, a departure in the record's words, at most 600 characters. A post that fails is Elixir's own story, as is any story the model leaves out. A run counts once against the day's 50, however many requests it takes, and every request counts toward the clan's monthly cap; [Limits](/docs/limits) has what a run costs. Without a key nothing changes. MCP and JSON API unchanged.
