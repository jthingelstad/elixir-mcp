# More moments in your Timeline

Elixir already reads your friends' profiles. Now your Timeline tells more of what changes between two reads.

- **King Tower**: "Pip reached King Tower level 15."
- **A maxed card**: "Pip maxed Hog Rider.", with the card's art.
- **12 wins in a challenge**: "Pip won 12 in Grand Challenge."
- **A best challenge run**: "Pip's best challenge run is now 9 wins."
- **Years played**: "Pip has played Clash Royale for 3 years."
- **Card Mastery, every 5 levels**: a day's Mastery levels are one item, like "Pip reached Mastery level 5 with 3 cards", with their cards. Other badges tell every level.
- **Sessions say how they were won**: three-crown wins and overtime wins show on the session.

Small moments are one line each, and a few in a row fold into one row you tap to open. Each keeps its own Cheer.

These start from Elixir's next read of each profile, so nothing old shows up.

MCP 13.5.0. JSON API 5.1.0 unchanged.
