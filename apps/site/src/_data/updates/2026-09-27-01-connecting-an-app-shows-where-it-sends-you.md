# Connecting an app shows where it sends you

When an app asks to connect to your Elixir account, the page now shows the address it will send you back to beside the name it chose for itself, and says plainly when it is one of Elixir's own apps. Apps can now disconnect themselves with a standard revocation request, and sign-in codes to one address are limited the same way whichever page asked for them. Contract 9.12.1; JSON API 2.6.1.
