# Remove a suspended agent from view

A suspended agent can now be removed from view, from its console's Settings. It leaves the console's agent switcher and the Agents table for a folded Removed agents list at the foot of the Agents page, so the agents you run are the ones you see. Nothing is deleted: a removed agent stays suspended, keeps its address, its keys and its history, and still opens at its own console, where Restore puts it back among your agents (resuming it does too). An active agent is suspended first. MCP 11.7.2 and JSON API 3.1.0 unchanged.
