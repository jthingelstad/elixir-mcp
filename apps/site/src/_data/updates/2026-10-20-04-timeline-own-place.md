# The Console's Timeline keeps its own place

The Timeline dot in the Console now clears when you open your Timeline,
whether or not an agent is connected. The page marks what the record
learned since your last visit **New** and draws a line under the last of
them. Opening it changes nothing your agents have read, and an agent
reading the timeline no longer clears the dot. Rows no longer say
"Unread by connections". On an agent's console the same holds for the
agent's Timeline.

MCP 11.13.1 and JSON API 3.2.0, unchanged.
