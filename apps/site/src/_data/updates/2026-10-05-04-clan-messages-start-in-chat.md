# Clan messages start in chat

New routine Actions start with clan chat. Award updates, final awards and important rule announcements also offer a durable Inbox message. Switching channels keeps your edits, and sent receipts preserve the channel and reviewed words. Review later leaves the Action open; the app explains the reported daily Inbox limit and masked text without predicting availability or resending. Existing decisions and receipts stay intact. MCP 11.2.3 and JSON API 3.0.0 unchanged.
