# The old request form and its admin pages retire

Elixir has been open to anyone with an email address since signup became
free, so the parts left from when people asked to join are gone: the
request form's address, `/api/request-access`, now answers that it is not
found, and signing up is the way in.

For Elixir's staff, **Admin › Requests** and **Admin › Beta pulse** are
gone too. Admin opens on **Accounts**, and old links to either page,
including the Console's, land there.

MCP and the JSON API unchanged.
