# The clan directory stays quick as Clan grows

The [clan directory](/clan/directory) now finds the clans that saved
their rules without reading the rest of Clan, so it opens just as fast
when many clans run on Elixir. Open it from **Find**, under
**Clan directory**.

Find's line about the directory now says what it lists: clans that saved
their rules in Elixir, by name, never ranked.

MCP and JSON API unchanged.
