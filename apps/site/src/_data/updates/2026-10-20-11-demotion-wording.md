# A demotion's Leader Message no longer says "Keep playing"

When an Elder moves back to Member, the Leader Message Elixir Clan
offers names the member and now reads "… moves from Elder back to
Member for now, and Elder can come back." The old "Keep playing and it can come back" could
read as a reason, and a demotion never says why. "Draft in our voice"
says at least this much, so its drafts lose the phrase too.

MCP 11.13.1 and JSON API 3.2.0, unchanged.
