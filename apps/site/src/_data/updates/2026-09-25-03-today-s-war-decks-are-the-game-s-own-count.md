# Today's war decks are the game's own count

Who has played their war decks today now comes straight from the game's own daily counter, as Elixir last read the race. It used to add recorded war battles placed on the day by the clock, which could run ahead of the game and, for a clan whose day rolls a little early, show someone with more than four decks. The count can now trail play by a few minutes instead of guessing ahead. Contract 9.1.2.
