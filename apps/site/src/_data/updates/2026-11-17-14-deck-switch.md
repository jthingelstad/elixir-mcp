# When a friend takes up a new deck

Your Timeline now says when a friend switches decks: "Pip switched to Hog Rider cycle on Trophy Road: 3 battles, 2 wins.", with the new deck's eight cards.

- **Each mode on its own**: Trophy Road, Ranked and Clan Wars battles are different games, so a deck played in one is never counted in another.
- **Once it is real**: three battles with the deck within a week, after two weeks without it in that mode, and only when they were playing another deck before.
- **One a day**: two new decks tried in one evening are one moment, the first.

The deck is named the way players name it. A name is just a name, never a judgment of the deck.

These start from Elixir's next read of each battle log, so nothing old shows up.

MCP 13.6.0. JSON API 5.1.0 unchanged.
