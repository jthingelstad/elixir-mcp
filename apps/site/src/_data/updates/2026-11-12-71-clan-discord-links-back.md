# Your clan's Discord posts link back to Elixir

Each post Elixir makes in a clan's activity channel now ends with one
link, **Open in Elixir**, to the page it is about: the battle, the clan's
War or Standings, the member's player page, or the clan's Feed. Discord
shows no preview for it, so the channel stays a list of stories. It
holds whether Elixir or the clan's own model wrote the words.

MCP and JSON API unchanged.
