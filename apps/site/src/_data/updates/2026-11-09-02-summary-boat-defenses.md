# Your 30-day summary leaves out boat defenses

When an enemy attacks your clan's boat, your defense deck answers, but you did not play that battle. Every other count in Elixir already left those defenses out; the 30-day summary still counted them, so it could show a couple more war battles than the same 30 days read anywhere else. It now leaves them out too, and still says how many defenses there were.

MCP 11.18.5; JSON API 3.4.0 unchanged.
