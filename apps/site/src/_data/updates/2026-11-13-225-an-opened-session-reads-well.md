# An opened session reads well

Tap **Open session** on Home (or **View games** on a player's page) and you now
see each battle as its own row, newest first: win or loss, the score,
who you played (and your teammate in a 2v2), a duel's games, the
trophies it moved and a link to the battle. Battles sit under the deck
they were played with, with its cards.

MCP and JSON API unchanged.
