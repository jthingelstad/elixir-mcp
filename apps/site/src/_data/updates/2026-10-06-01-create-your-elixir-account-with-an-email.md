# Create your Elixir account with an email

Anyone can open a free member account by verifying an emailed link or code. Start in Console by adding your player, read your record in Ladder, and open Clan with the same account. An agent or collector is optional. Collector approval and recording limits still apply, and an existing account restriction cannot be removed by signing up again. Contracts remain MCP 11.2.3 and JSON API 3.0.0.
