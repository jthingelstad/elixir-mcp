# Documentation that describes Elixir as it is

The documentation now describes only what Elixir does today: open signup, Clan inside your Elixir account, Ladder beside the Console, six kinds of email and the card catalog's facts. Retired pages and sections are gone, including War decks, Leaderboards, Card of the Week and Top 100, along with version tags in the prose. elixir_examples now says it has ten examples. MCP 11.2.4; JSON API 3.0.0 unchanged.
