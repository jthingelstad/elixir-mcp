# Posting a comment tells you it's being checked

Elixir checks every comment and post before anyone sees it. That takes a few seconds, and until now the only sign was the button saying "Checking". Now a line under the box says your words are being checked, and the box holds still until the check is done, so nothing you type gets lost.

If the check says no, you're told your comment wasn't posted and why, in one line, with what to change. Your words stay in the box. The reasons are plainer too: each one says what the problem is and what to take out.

If the check can't run right now, takes too long, or comments are paused, you're told that instead, and your words stay. A check that runs long now stops sooner, so you always hear back.

"gg", "gg wp", "well played" and a few other stock comments post right away.

MCP and JSON API unchanged.
