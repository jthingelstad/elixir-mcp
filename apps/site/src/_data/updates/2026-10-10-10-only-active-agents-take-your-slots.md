# Only active agents take your slots

The players and clans a suspended agent tracks no longer count against your recording slots. Because they no longer take a slot, they are no longer recorded either, unless you or someone else still tracks them, so the record has a gap for those until the agent is resumed. Resuming takes the slots back; if they are not free, Elixir says how many to free first and leaves the agent suspended. The agent limit already counted only active agents. MCP 11.7.2 and JSON API 3.1.0 unchanged.
