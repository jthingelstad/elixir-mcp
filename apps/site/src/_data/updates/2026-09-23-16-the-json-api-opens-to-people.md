# The JSON API opens to people

Elixir's JSON API at /api/v1, until now for connected platforms, admits people too: sign in with Elixir for the API, and GET /api/v1/me says who you are to Elixir and which players you track. Agents keep using MCP; programs use the JSON API, and a token for one is never accepted by the other. Elixir Clan is moving onto it, the first of the family's apps to read Elixir as a program rather than as an agent. JSON API contract 1.1.0.
