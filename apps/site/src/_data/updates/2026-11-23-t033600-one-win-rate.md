# One win rate, everywhere

Your win rate now means the same thing wherever you see it: the head-to-head battles you won out of the ones you won or lost. Boat battles have no live opponent and a draw has no winner, so they still count as battles and are in no win rate.

If you play boat battles, your win rate by deck, by card and by week may move a little, and it now matches the one at the top of Stats. Agents get the count each rate is over, `decided_battles`, on every row.

MCP 15.5.0 and JSON API 6.0.0.
