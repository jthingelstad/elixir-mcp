# Apps that sign you in with Elixir see your profile image

The card you pick in Settings › Profile now reaches apps that sign you
in with Elixir, like Elixir Drop. `GET /api/v1/me` gives your profile
image with where Elixir crops it, so Drop can show the same picture you
see here.

Mirror gets a crop of its own, so its picture fills the circle.

MCP unchanged; JSON API 5.1.0.
