# An action's page reads top to bottom

An action's page is one column now: the reason and its numbers, then folds for what it comes from, its message and its history, then the buttons. A removal that no longer qualifies offers Decline only.

"This week" on You here and on Home now keeps Monday's reset, so it matches The week between midnight and 10:00 UTC on a Monday. Standing and the minimums still read ISO weeks; nothing they judge moved.

MCP and the JSON API unchanged.
