# Run has tabs

Run, the leaders' area of a clan, now has five tabs across the top: **To do**, **Members**, **Exceptions**, **Rules** and **Setup**. They fit on a phone, so every one is a tap away.

**To do** is what the rules say to do next, with **Decided** beside it. **Setup** holds the pages you set once: awards, Discord, Model & voice and clan settings.

If one part of a page can't load, only that part says so, with **Try again**. Nothing you typed is lost. [The leaders pages](/docs/clan-leaders-pages) has the details.
