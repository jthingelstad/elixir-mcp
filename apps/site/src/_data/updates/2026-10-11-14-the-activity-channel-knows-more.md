# The activity channel's model knows a member's awards and recent moments

When the clan's own model rewrites the activity channel's posts, each member it writes about now comes with the clan's awards they hold, as the leaders announced them this season and last, and, while the channel posts Milestones, their last three moments from the past two weeks (never the one being posted). A departure is still told only the member's time in the clan and the weeks they played, and an award not yet announced is never told ([what each post is told](/docs/clan-policy#the-clans-activity-in-discord)). Clan chat drafts no longer mention a leader's note, since they take a tone, not a note. Settings and the Discord page now list every reason a rewrite keeps Elixir's own line, including a post that runs long, and [Limits](/docs/limits#the-table) lists the clan model's daily limits and monthly spend cap. MCP and JSON API unchanged.
