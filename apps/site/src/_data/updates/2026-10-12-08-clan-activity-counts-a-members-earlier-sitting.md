# Clan's Discord activity counts any earlier sitting toward a member's one a day

A member's standout sitting is skipped once anything from an earlier sitting that day was posted about them: a move, a new best, a league or the sitting itself, not only a sitting post. A post that told several members counts for each only what it said about them. A move and a new best from one sitting that both arrive at once are one post, even when nothing about the member was posted earlier that day. MCP 11.11.2; JSON API 3.2.0 unchanged.
