# Badges: the two Royal Tournament badges, and typos

The Elixir Gym's second run over the badge tools. Some badges exist twice, an original and a newer version that most players now hold. The badge tools now name both and count the distinct players holding either, so asking about Royal Tournament Rank no longer shows almost nobody holding it. A misspelled badge name now gets suggestions instead of a flat refusal. And badge counts across everyone now include only the players Elixir records today, not every profile it has ever read.
