# Weekly award standings no longer wait on a member who sat out the war

A weekly award standings Action could say a points award's standings were "not ready" when one member had not opened the game since before the war week began. The game leaves such a member off that week's race, and Clan read the missing row as unknown points. It now reads it as what it is: no points and no decks that week. The podium is shown, and a season's points and attendance awards are decided rather than held. A week the record did not read at all still waits.

MCP and the JSON API unchanged.
