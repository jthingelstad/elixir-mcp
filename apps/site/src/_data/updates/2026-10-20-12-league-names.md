# Path of Legends leagues go by their names in the game

Elixir now writes Path of Legends leagues the way the game does: Master
I, Master II and Master III, where the timeline and the milestone mail
said Master 1, Master 2 and Master 3. Champion, Grand Champion, Royal Champion and Ultimate
Champion are unchanged.

In Elixir Clan, "Draft in our voice" now names a member's best league
in a season Elixir recorded, with the season, where it gave the model a
bare number. The profile's own best is no longer used: it can come from
before the game's July 2025 change to seven leagues, when the same
number meant a lower league.

MCP 11.13.2 (a correction) and JSON API 3.2.0, unchanged.
