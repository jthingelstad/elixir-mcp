# Path of Legends leagues go by their names in the game

Elixir now writes Path of Legends leagues the way the game does: Master
I, Master II and Master III, where the timeline and the milestone mail
said Master 1, Master 2 and Master 3. Champion, Grand Champion, Royal Champion and Ultimate
Champion are unchanged.

In Elixir Clan, "Draft in our voice" now names a member's best league
in a season Elixir recorded, with the season, where it gave the model a
bare number. Reaching Ultimate Champion is a big deal, so it leads a
welcome's or a promotion's story angles, and it counts even from before
Elixir's record: only Ultimate Champion has a rating, so a rated
profile best is one. Any other profile best is no longer used: it can
come from before the game's July 2025 change to seven leagues, when the
same number meant a lower league. A member who never played Ranked is
never said to have reached Master I.

When a member reaches Ultimate Champion, Clan's Discord says they made
it all the way there.

MCP 11.13.2 (a correction) and JSON API 3.2.0, unchanged.
