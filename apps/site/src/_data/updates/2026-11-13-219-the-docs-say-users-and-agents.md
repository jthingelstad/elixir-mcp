# The docs say users and agents

The developer guides follow the JSON API's 5.0.0. The JSON API and
Integrations pages are gone. [Sign in with Elixir](/docs/sign-in-with-elixir)
now covers `GET /api/v1/me`, the one request an app makes there, and
its errors. [Users and agents](/docs/connections) names the two kinds of
connection Elixir has. Attested facts, the things Clan says about a
clan, are described on [the timeline](/docs/timeline#attested-facts).

MCP's own words follow too. The brief and a hidden tool's hint name only
people and agents. A few output descriptions no longer say `/api/v1`
serves a tool's rows.

MCP 13.0.1, a patch, and JSON API 5.0.0, unchanged.
