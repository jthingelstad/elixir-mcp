# Battles: event play kept out of the meta, and counted as events everywhere

The Elixir Gym's second run over the battle tools. The meta tools already left out event battles and drafted decks for whole seasons. They now do the same for custom date ranges and single players or clans, so a week's meta no longer mixes in a boosted event deck. Everywhere else, event battles are counted as events, never as casual play. Asking for one deck's battles in a date range now gives that range's totals, not the deck's lifetime. Contract 6.31.0.
