# Empty pages sit flat

When a page or a tab has nothing to show yet, it now says so in a quiet
line where the page's words start, like Home does, instead of in a big
centred box.

- "Nothing at this address" and the staff-only page look like every other
  page: a title, one line, and Go to Home.
- Settings says Stats, not Ladder, for the page your main player opens on.
- An agent's Timeline in Settings opens a session with the same words as
  Home: Open session, Open crossing.
- On your phone, every text box is a full-size tap.

What each page shows, and who can see it, is the same.

MCP and JSON API unchanged.
