# Timeline follow-ups read the whole sitting

A sitting's battles_performance follow-up now covers the sitting's last battle as well, so its totals match the item. A player's own move to or from a clan now leads only to that player's summary, since the clan may be one nobody records; a clan's own member moves still lead to its roster. A member read says a sitting is cut only when a cut sitting is on the page it serves. MCP 11.9.1; JSON API 3.1.0 unchanged.
