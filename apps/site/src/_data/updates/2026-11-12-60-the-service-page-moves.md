# The service page joins Status and data

The signed-in service page is gone. What it said that is about Elixir as
a whole is on [Status and data](/data), which now also lists each
collector: its name, who runs it, whether it is keeping up and whether
its release is signed. The rest, the counts Elixir's staff run the
service by, moved into their own pages.

If you run a collector, its own page is where it was in **Settings ›
Collectors**. If you want to run one, Status and data links to **Run a
collector** when you are signed in.

Old addresses, bookmarks and links in mail still open the right place.

MCP and the JSON API unchanged.
