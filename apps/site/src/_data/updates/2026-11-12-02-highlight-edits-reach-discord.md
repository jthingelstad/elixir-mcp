# A highlight's new words reach Discord and your agents

When you change a highlight's words, a timeline that goes to a Discord
channel now edits the line it already posted to show the new words, and an
agent reading the timeline from where it left off is given the new words
too. Before, both kept the first words. A new highlight also reaches that
Discord channel within about a minute, instead of waiting for the player's
next battle. If you delete a highlight, a line already posted to Discord
stays there.

MCP 11.20.1 (an edited `battle_highlight` comes back at a higher
`revision` under the same `id`); JSON API unchanged.
