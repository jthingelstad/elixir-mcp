# War history: when a clan's war trophies are counted

The Elixir Gym's first run over the war tools. A week's war trophies are the clan's figure going into that race, and the week's own gain or loss lands in the next week's figure. The tools now say so, so a closed week is no longer read as finishing on the number it started with. Asking about a week a season never had now says it never existed, not that it is still to come. Contract 6.29.0.
