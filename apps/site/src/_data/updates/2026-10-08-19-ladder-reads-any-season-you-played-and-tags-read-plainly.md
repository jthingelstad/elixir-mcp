# Ladder reads any season you played, and tags read plainly

Ladder now has a Season switch beside the page's freshness: the current season, the last one, and every season your player has battles in since Elixir started recording them, named Season 136 as everywhere else. The season is part of the address (/ladder?season=135), so a link keeps it, a reload keeps it, and the season home, Days played, Decks and Cards all read it. In the first days after the roll, when the current season has no battles yet, Ladder opens on last season and says so, with the new season a click away. The Tuesday Arena email and milestone notes now open Ladder on the season they describe, and the Monday clan report links the race's own week, so an older mail still opens what it described. Player and clan tags now draw in a fixed-width face with a slashed zero across Elixir, Ladder and Elixir Clan, so a 0 and an O never look alike, as they did on a Tag not found headline. MCP 11.5.2 and JSON API 3.1.0 unchanged.
