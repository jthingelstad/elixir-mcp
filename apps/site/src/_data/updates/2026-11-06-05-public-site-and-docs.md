# The public site and the docs, rewritten

The home page says what Elixir is in one breath and shows what it is recording right now. Status and data is one page now: right now, the record, battles by day, what is recorded and how long, and the machine-readable ways in. Cards can be cleared when a filter finds nothing, and each card links to your own cards in Ladder when you are signed in. Support reads as one argument, in one column, and says again that paying changes nothing.

The docs are in three groups: Use Elixir, Connect an AI, and Build and reference. Long pages split into pages that each answer one question, and they use the same words as the app. A link to an old page or section still lands in the right place, including the ones in mail you already have.

Updates opens on the newest month, with the earlier months each on a page of their own. Contract versions wait behind a switch. On a static page, Help opens where you are and files a note with the page attached, and Search takes you to the search sheet.

MCP 11.18.0, JSON API 3.3.0 unchanged.
