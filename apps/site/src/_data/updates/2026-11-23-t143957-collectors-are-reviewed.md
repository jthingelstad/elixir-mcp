# Every collector is reviewed before it starts

Want to run a collector for Elixir? You still raise your hand at Settings › Collectors. Now that sends a request, and the maintainer reviews it before your collector starts.

- Your collector's page says **Waiting for approval** until then. There is nothing more you need to do.
- Its token is ready to reveal right away, so you can set the machine up while you wait. It fetches nothing until it is approved, then it starts on its own.
- While one request waits, you can't ask for another.

Why: what a collector sends goes straight into the record, so each person who runs one is someone the maintainer has said yes to.

Collectors already running are not affected.

MCP and JSON API unchanged.
