# Saved war intent guides the scheduled war-deck check

The Discord agent’s scheduled war-deck check now follows saved participation intent. Participating permits it only in the right war phase after a fresh policy read; not participating skips it, and unspecified or unavailable context makes it wait. The agent refreshes before planning and firing. Other agent content keeps its own rules. Contract 11.2.0; JSON API 3.0.0 unchanged.
