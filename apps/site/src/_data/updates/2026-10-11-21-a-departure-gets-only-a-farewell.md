# A departure gets only a farewell

When the clan's model edits Elixir Clan's Discord activity channel, its post for a departure may now add only a thank-you or a farewell in English ("Thanks for everything!", "Good luck out there!") around Elixir's sentence for it. Anything else beside that sentence, in any words or any language, is refused, and the departure is posted in Elixir's words. A post that gives a time of day such as "at 18.05" is refused too, as "at 6:05 pm" already was. MCP and JSON API unchanged.
