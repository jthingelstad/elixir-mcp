# Your Timeline by mode

Your Timeline has a **Mode** list beside its chips: **All modes**, **Trophy Road**, **Ranked**, **War** or **Casual**. Pick one and the feed shows only that mode's sessions and moments. It works with the chips, so **Friends** and **Ranked** shows your friends' Ranked play.

Casual covers everything else: friendly battles, 2v2, party modes, challenges, events and tournaments. Things that aren't about one mode, like badges and cards, show under **All modes**. The mode stays in the page's address, so a link opens on it, and it's kept for your next visit on the same device.

MCP and JSON API unchanged.
