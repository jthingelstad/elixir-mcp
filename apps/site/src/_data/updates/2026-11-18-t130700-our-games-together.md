# Your games together

Open a followed friend's player page and choose **Together**. See when
your verified player **Teamed up** with them or **Played against** them in
the last 30 days, one mode at a time. Each recorded battle opens its own
page.

If you have several verified players, choose which one to read. A gap in
the record stays unknown.

MCP 14.1.0 · JSON API 6.0.0.
