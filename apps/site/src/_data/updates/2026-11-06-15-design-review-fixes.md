# Ten fixes from the design review

Every place now shares the top bar's edge, so the page no longer jumps as you move between Home, Ladder and Clan. A clan's name leads in the display type, and a page inside it steps down.

On Ladder, Battles reads down one column: the time, then Won or Lost in the Record's colours, then the opponent. A day with one sitting no longer repeats itself in a row of its own. On a phone, Days played starts at today with a line for the days to come, and the mode chips stay on one line. The player and season lists show only the name when closed.

In Clan, You in the clan says whether you are meeting the minimum first, and on a phone the roster is two lines a member. Each page now has one freshness pill, which tells you what its colour means when opened.

New accounts get one way in: every place sends you to Home's first step, and each step says what will happen. Names no longer show the game's colour markup like `<c5>`, including names already stored. Wide Feedback rows, usage meters and the data page's range buttons are fixed too.

MCP 11.18.4, JSON API 3.4.0 unchanged.
