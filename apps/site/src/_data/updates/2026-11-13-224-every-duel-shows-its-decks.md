# Every duel shows its decks

A battle played as three games on three decks, like an event's
multi-deck mode, now shows each game's decks for both players on its
battle page. Before, the page said there was no deck on either side.

Tap a game to see its decks. Where Elixir kept a game's crowns and
towers, the game shows them too. Where it didn't, you see the decks and
no score, never a guess.

MCP 13.0.2: `battles_query` carries each game's result on these battles
too. JSON API unchanged.
