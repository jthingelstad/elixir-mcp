# Clan is part of Elixir

Clan is a set of features inside Elixir, not an app of its own, and
Elixir now names it that way: plain Clan, everywhere. A fact Clan
recorded says it was said in **Clan**. The link at the foot of Clan's
morning mail goes straight to the clan's **Feed**, and Clan's old
feedback pages open your feedback in Settings.

MCP 12.1.1 (wording only; no field changed). The JSON API is unchanged.
