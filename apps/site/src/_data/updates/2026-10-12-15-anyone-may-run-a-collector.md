# Anyone may run a collector

Raising your hand at Console ▸ Collectors ▸ Run a collector now approves it on the spot: you land on your collector's page with its token ready to reveal once, and nobody has to sign off first. What keeps the record honest is what every collector's results must pass on every submit: the API's shape, the right player or clan, battle ids drawn from the battle itself, the collector's identity stamped by the server, and an automatic drain for one that keeps dropping work, with the maintainer able to revoke any token at once. Your collector turns active with its first result that passes. If the token lapses or gets lost, New token on the same page stages a fresh one. The fleet still shares one rate budget, so more collectors add resilience, not quota. [Running a collector](/docs/operators) says it all. MCP 11.11.2 and JSON API 3.2.0 unchanged.
