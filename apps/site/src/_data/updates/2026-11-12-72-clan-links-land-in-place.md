# A clan's link and a war week's link open the right page

A clan's name in mail or in a clan's Discord channel now opens the clan
itself: Clan for its members, and for anyone else the clan directory,
searched for that clan. A race week's link opens that week of the clan's
War tab, not only its season. Older links in your inbox land the same way.

In the clan directory, a clan you are not in no longer links to a page
that went with the Console; its tile says everything Elixir shows about it.

MCP and JSON API unchanged.
