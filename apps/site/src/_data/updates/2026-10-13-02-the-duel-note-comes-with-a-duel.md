# The duel note comes with a duel

`battles_query` explains how a river race duel row collapses its games (`rounds_played`, `rounds[]`, crowns summed across rounds) in a note, and until now every answer carried that note, even when no duel was on the page. It now comes only with a page that holds a duel, as the notes about unequal towers, leaked elixir and the trophy floor already come only with the rows they describe. No field changes. See [Duels and boat battles](/docs/battles#duels-and-boat-battles). MCP 11.12.1; JSON API 3.2.0 unchanged.
