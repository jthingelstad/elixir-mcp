# The docs now match what is on the screen

Every doc page was read against the app after the redesign. Buttons, tabs and settings are now called what they are called, and they are where the docs say they are.

If you lead a clan: an action is closed with Done or Decline, and Clan opens on Today, with Waiting and Decided. A week in Season shows the running week so far, and only war names members. Scheduled mail and clan mail keep different times, and the Emails page says which.

If you are new: a new account lands on Home's first steps, and Invite clanmates is on Ladder's Season tab. If you run a collector, raising a hand starts at Settings › Collectors › Run a collector.

The notice shown when another account verifies your player now links to your players in Settings, and says to make another player your main player.

MCP 11.18.1, JSON API 3.4.0 unchanged.
