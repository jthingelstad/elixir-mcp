# Share one Timeline item

**Share** gets a link to an update, post or question you can see. No need to
write a post first. Anyone holding the link can read that one item, with
its game names, facts and cards, then sign in or create an account to see
more.

Comments, cheers, private nicknames and private Clan activity stay inside
Elixir. Edits show on a shared post; a removed post stops opening. Previous
public battle, session and post links no longer open. Your signed-in pages
still work.

MCP 13.12.0. JSON API 5.1.0 unchanged.
