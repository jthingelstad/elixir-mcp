# A sign-in link asks before it signs in another screen

When you open the link in a sign-in email, the device you opened it on is signed in, as before. If the email was asked for on a different device or browser, and that page may still be waiting, you're now always asked: **Sign in the other screen too?**

Before, the waiting page was sometimes signed in without asking, when both were on the same network. Now nothing else is signed in until you tap **Yes, sign in that screen too**. Tap **No, just this device** and only the device you're holding is signed in.

If you didn't ask for the email yourself, or you're not sure, tap No.

Opening the link in the same browser you asked from works as before: no question, and the waiting tab signs in on its own.

MCP and JSON API unchanged.
