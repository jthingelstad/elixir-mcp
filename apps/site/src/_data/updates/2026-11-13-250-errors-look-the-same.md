# Errors look the same everywhere

More polish.

- When something can't be read, every page says it the same way: what
  could not be read, and **Try again** where trying again can help.
- On a phone, **Docs** is in the footer when you're signed out, so the top
  bar stays on one line.
- Your own player page drops the "You" label.
- Home's filter chips on a phone scroll as one row, New included.
- A battle's games use the same tabs as everywhere else.
- Settings' Emails and Usage pages, the bell's "See more" line and your
  clan's gold edge are tidier.

MCP and JSON API unchanged.
