# What the clan's model is never told, said exactly

Settings and the Clan docs now say exactly what the clan's model is sent. The one free-form text it gets is what you type in **What should it say?** when you draft, as you wrote it. Notes saved on an Action, yours or another leader's, are never sent, and neither are tags, holds, a removal's reasons or inactivity numbers, or a member's share of the clan's fame. The awards page now says the model is told the winners and their numbers, while Elixir still writes the complete list of recipients itself. Nothing about what is sent has changed; only the wording. MCP and JSON API unchanged.
