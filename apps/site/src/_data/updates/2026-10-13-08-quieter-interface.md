# A quieter Elixir

Elixir gives the record and your next action more room. Product tabs and
the left rail stay familiar, with quieter colours, clearer page titles
and fewer framed panels.

The clan roster uses the full page. Standing starts with your own status
and the clan's groups. Actions put the evidence and message alongside the
decision. The Console timeline reads as events, with Discord sharing
under **Manage sharing**. Clan settings show their current state in rows;
open a setting to edit it. Explanations, delivery history, completed setup
and invitations expand when you need them.

Your existing permissions, recording warnings and decision checks stay
in place. Phone layouts use the same controls and record.

MCP 11.13.0; JSON API 3.2.0.
