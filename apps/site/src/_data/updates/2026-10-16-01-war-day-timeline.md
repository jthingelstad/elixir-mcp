# The timeline works on war days again

From the first war day on Thursday, every timeline that reached a
tracked clan's war line failed instead of answering, including the
Discord agents' event polls. It answers again, with the decks tally for
the war day in progress.

A search with a space in it also works again: a roster search such as
"King Thing" in Elixir Clan, and any address on the Console or the API
whose query wrote a space as a plus sign, had been answered with an
error page from the edge.

MCP 11.13.1; JSON API 3.2.0, unchanged.
