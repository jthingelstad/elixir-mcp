# The bell is a small inbox

The bell now opens as a small box under it on a wide screen, and slides up
from the foot on a phone. It shows **Needs you** first, then **New**, then
**Earlier**, so you can tell what is waiting on you from what just happened.

Every line is one tap and opens where it points. The **Open** buttons are
gone. **Follow back** is still there for a new follower.

The number on the bell now shows on a phone's tab too. Open a line and come
back, and the bell is where you left it, with the rest of what was new still
marked. Escape puts it away and returns you to the bell.

MCP 13.1.1 and JSON API 5.1.0 unchanged.
