# Feedback you can work through

Your feedback list can now come back compact: each item's title, status and whether it has an answer, without the bodies, so a long history fits on one page. Read one item whole by its number, with the replies that follow it and the items that name it as related. When the maintainer needs one more fact, an item's status is now needs_info, a question for you; answer it with a reply (follows_id), and the Console offers "Answer the question". To say two of your items are related, name the other one in refs as kind feedback. MCP 11.10.0; JSON API 3.2.0.
