# Weekly, Daily or Off

In **Settings › Emails**, your digest is now three choices side by
side: **Weekly**, **Daily** or **Off**. Tap one and that's it. No
separate switch to find first.

In the **clan directory**, each clan's card now ends with its members
and how long it waits before a removal, in the same spot on every card.
Your own clan says so there.

MCP and the JSON API unchanged.
