# The clan's own model knows the clan

"Draft in our voice" used to tell the model almost nothing, so its drafts came back generic. Now it is told what Elixir records: the clan (its name, recruiting words, goals, member count and last war weeks), the Action's own evidence, the member it is about by name (trophies and best, arena, career wins, collection level, time in the clan, recent war weeks as decks and points, recent moments, awards held) and your note as you wrote it. It picks one or two of those to make the words personal, and marks anything it says that it was not told for you to check. A removal or a departure is told only the member's time in the clan and the weeks they played, and tags, private notes, holds and a removal's reasons are never sent. The clan's activity channel gets the same facts for each post, writes members reaching the same kind of milestone together as one post, and refuses a post that drops a name, adds a number or name it was not given, or carries a link. On Social ▸ Discord, **Preview the last 5 in this voice** shows what the channel would post in the voice you are writing, without posting anything. A careful draft that takes longer than one request now keeps going until it lands. Migration 0220; MCP and JSON API unchanged.
