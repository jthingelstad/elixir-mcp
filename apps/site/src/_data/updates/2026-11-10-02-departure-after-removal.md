# A departure names the removal it follows

When a leader kicks a member whose removal Action is still open, Clan's departure Action now says so: "Elixir recommended removing them in Action #N", with **Kicked** offered first. A leader still confirms it; **Left** and **Ignore** stay there, and nothing is recorded as a kick until someone presses the button. The removal is withdrawn, and its History points to the departure. A departure with no removal before it asks as it always has.

MCP 11.18.6 and JSON API 3.4.0 unchanged.
