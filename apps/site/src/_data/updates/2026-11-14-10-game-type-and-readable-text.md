# A little more Clash Royale

Main page titles use the official Clash Royale font. Body text, smaller
headings, names in lists and buttons use Rubik, a softer face that stays
clear on your phone.

Email uses the same pair when your mail app supports it, with readable
fallbacks when it doesn't. Your sign-in code keeps its clear, spaced digits.

MCP 13.1.1 and JSON API 5.1.0 unchanged.
