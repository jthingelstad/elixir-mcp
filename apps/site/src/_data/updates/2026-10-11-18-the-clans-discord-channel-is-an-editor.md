# A clan's Discord channel tells stories, not lines

A clan's activity channel (Elixir Clan's Social ▸ Discord) no longer copies the timeline line by line. It now works as an editor. What one battle did (an arena reached, a new best, a promotion) is one post. The same milestone reached by several members at once is one post naming each of them, and a standout sitting is one post that grows. Each is written as a sentence or two, with no time and no link, and with what Elixir knows: the deck the battle was won with and its record this season, a second promotion in a day, the clanmates already in that arena. A story waits a few minutes until it is complete, so it usually lands about six minutes after the activity. Some things are skipped by rule, and the page lists each skip with its reason: a badge level below the top, a story that only grew, or something already told. A post is edited only when its story truly grows, never posted twice. The timeline cross-post keeps its lines ([the clan's activity in Discord](/docs/clan-policy#the-clans-activity-in-discord)). MCP and JSON API unchanged.
