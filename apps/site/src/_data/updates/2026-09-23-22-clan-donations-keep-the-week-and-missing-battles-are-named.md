# Clan donations keep the week, and missing battles are named

The Elixir Gym's third run over the clan tools. A clan's weekly donation total now keeps the highest number seen that week, as each member's already did, which repairs two weeks that read 10. Clan standings and participation now name any member whose battles Elixir mostly missed that week, so a quiet-looking member is not mistaken for an inactive one. And a clan's daily member averages leave out anyone who left that day. Contract 6.36.9.
