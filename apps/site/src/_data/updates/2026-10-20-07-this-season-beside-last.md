# Ladder sets this season beside the last

Ladder's season home has a third panel beside "This week vs your last 4"
and "Before and since your main deck": the season you are reading beside
the one before it, in the mode you chose. Each side shows won–lost, win
rate, net trophies where trophies move, and how many decks you played,
each with the battles it is over. A season still running is "so far",
set beside last season to the same point and beside all of it; a past
season sits beside the one before, both whole. A side with fewer than 10
decided battles is not set beside another, and the page says so, as it
does when last season has no battles in the mode. Like the other two,
the panel shows numbers, never which side is better.

Days played has always put a war battle on the day you played it. That
is now written down: Ladder shows your battles one by one, war included.

MCP 11.13.1 and JSON API 3.2.0, unchanged.
