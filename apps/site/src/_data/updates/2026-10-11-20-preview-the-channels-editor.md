# Preview the activity channel's editor

On Elixir Clan's Social ▸ Discord page, **Preview the last 5 in this voice** now shows what the clan's model would do as the channel's editor with the five newest stories from the last week, in the voice in the box: each post with the stories it tells and Elixir's versions of them, each skip with its reason, and each story kept in Elixir's words with why when the model's post or skip was refused. The preview is one request with no lookups, so a real run may say more; it posts nothing and counts as one of the leaders' drafts for the day. The editor's checks are also tighter: a departure keeps Elixir's sentence for it word for word and never gains a reason, a story over three hours late must say when in words ("earlier today", "yesterday"), a post that retells a story another post told is refused whole, and a name two current members share is not looked up. The page, Settings and the docs now call it the editor, and a post the clan's model wrote is marked "by the clan's model". MCP and JSON API unchanged.
