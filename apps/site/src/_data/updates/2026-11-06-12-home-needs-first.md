# Needs you settles sooner

The top of Home no longer waits for your clan's numbers. Needs you now reads on its own, so it settles right after the page opens instead of pushing everything down a few seconds later. If that read fails, the clan card's own copy fills it in. Latest skips players with nothing in the last week. Its five items, words and order are unchanged.

MCP 11.18.3, JSON API 3.4.0 unchanged.
