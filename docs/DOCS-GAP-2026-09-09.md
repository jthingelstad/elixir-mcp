# Docs gap audit (2026-09-09)

Inventory built from code, then diffed against `apps/site/src/docs/`. Status
values: **missing** (no page covers it), **partial** (covered without the
exact endpoint, field, code or limit), **stale** (was true, no longer), **wrong**
(contradicts the code today), **ok**. Code cites are `file:line` as of commit
`7c5b113`. The site is the product's only description of record, so every
"missing" here is a capability a developer cannot learn without reading source.

Two premises in the brief did not survive contact with the code and are
corrected throughout: there is no `packages/contracts/CHANGELOG.md` (the
changelog is `packages/contracts/src/changelog.ts`, served by
`elixir_changelog` and rendered at `/data/changelog`), and there is no
`live_quota_exhausted` error code (the taxonomy is seven codes,
`packages/contracts/src/errors.ts:8-16`; live exhaustion is `quota_exceeded`).

## 3. Code inconsistencies found on the way (not docs; filed for follow-up)

1. Step-up 403 names the personal `resource_metadata` even at `/a/…` doors (`handler.mjs:270` vs `:136`).
2. `-32029` defined twice (`protocol.mjs:27`, `errors.ts:27`); `errors.ts:13` ties `quota_exceeded` to -32029 but the string code is only used by live and slot refusals.
3. `elixir_add_clan` defaults to `comprehensive`, which the member tier cannot hold (`elixir.mjs:748-752`, `roles.ts:86`).
4. `POST /api/feedback` rewrites category `other` to `general` (`routes/feedback.mjs:33-41`) while MCP and the DB accept it.
5. Handlers still clamp `limit` after 0.39.2 made the schema refuse (dead code).
6. No `Retry-After` on MCP/explorer 429s; explorer daily quota is HTTP 429 while MCP is JSON-RPC -32029 over 200.
7. `/i/<id>/mcp` OAuth is unreachable (integrations are token-only) though the resource shape is accepted.
8. `oauthmail` and `/api/auth` throttles are invisible (200 with "check your email").
9. `/oauth/token` has no rate limit.
10. `integration-api.mjs:202` validates the body before authentication.
11. `elixir_identify` is described as permanent but the SQL upserts.
12. Collection member limits exist only for integrations; console and MCP paths are unbounded.

## 4. What the rewrite does

New pages: **protocol** (reference), **recording** (data), **limits**
(reference). Rewritten: quickstart (per-client steps), agents (builder guide
with complete examples), events (payload floors and cursor code), roles
(corrections), integrations (gaps above), responses (cap number, `_meta`),
about, architecture (the two false pointers), privacy (retention rows),
operators (door specifics), connections (console map), methodology (link).
The generated `/docs/tools` is untouched. New pages are under `/docs/`, which
the edge router already routes by prefix, so only the test's `STATIC_PAGES`
list changes; `STATIC_LINKS` and the CloudFront function are unchanged.
