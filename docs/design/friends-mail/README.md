# Friends-first email comparisons

All 27 offline mail specimens, at actual 390 × 844 and 1280 × 900 viewports.
Before is main at `1021456b2`; after uses the same invented facts and clock,
with explicit ownership flags added. Full captures include the footer.
All images load from this checkout's existing local mirror; pixels and
external network requests are blocked. No real mail is sent or archived.

The digest puts each friend's name, highlights and words above the record,
without a competing numbers column. All mail shares the app's neutral dark
colors, violet actions, gold brand and verified-name checks. Email uses a
text check with an accessible label rather than unsupported SVG or avatars.

`node packages/mail/scripts/preview.mjs --out <directory>` regenerates
HTML, text and the manifest without sending. Screenshots use Playwright's
real viewport and full-page capture with only the local preview server
allowed. Native in-app browser review separately checked the phone digest,
feedback, Clan's verified title, a 320px sign-in code, and desktop digest.
The existing mail-layout journeys check all 27 variants at 320, 390, 820,
1280 and 844px landscape with every image blocked, ownership marks still
present, no overflow and primary actions at least 44px high.

[Content comparison](content-comparison.json): all 27 have the same words
and destinations, excluding the new explicit verification label and
allowing records to move below their friend's highlights. Transactional
text still comes from the relay's actual text alternative. This gallery
is browser QA, not an inbox service or a claim of testing every mail client.
