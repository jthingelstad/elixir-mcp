# 2026-11-13 — Dead CSS and the rail switcher go

The social pivot left styles behind for surfaces that no longer exist.
Deletions only; no page changes how it looks.

- **`packages/ui/src/Rail.tsx`:** `RailSwitcher` and `RailChoice` went,
  with the rail's `head` prop that only a switcher filled. Nothing in
  `apps/web` or `packages/clan-web` rendered one since the Console and
  Clan's own rail folded; only `packages/ui/test/rail.test.tsx` did, and
  its switcher tests went with it. Two assertions that a switcher was
  absent (`apps/web/test/app.test.jsx`, `e2e/console.spec.ts`) went too.
- **`packages/design/src/components.css`:** about 150 rules whose every
  selector names a class that no source file, template, site page or
  script writes. Each class was checked against every tracked file
  outside the stylesheet, with class names built at run time (`kit-av--`,
  `ladder-day--`, `mode-chip__dot--`, `activity__cell--`,
  `randomart__cell--`, `freshness--` and the rest) kept whole. Families
  gone: the rail switcher, Drop's promotion tile, the docs sidebar
  (`docs__toc`) and reference box (`docs-ref`), card meta (`card-modes`,
  `card-months`, `card-stat`, `card-thin`, the share bars on
  `card-tile`), the first-answer steps, Home's old top strip and Needs
  you block (`kit-home__top`, `kit-needs`, with its `kit-home-opens`
  animation), the feed sections and cards (`kit-fsec`, `kit-fcard`),
  `recording-summary`, the Clan subnav's links, and single leftovers
  (`stat__value`, `chart__head`, `gauge__fill`, `meter__mark`,
  `outcome--*`, `st-tools` and others). Six selector lists lost only
  their dead members. Comments that described only a deleted rule went
  with it.
- Kept although a test only asserts it is absent:
  `kit-feed__item--decision`, which the kit's canvas mapping
  (`2026-11-13-kit-from-the-canvas.md`) names for the feed.
