# 2026-11-05: Home at its new address (step 3a)

Home is built at `/home`, `/home/timeline` and `/home/friends`, wearing the new
shell, and is not yet the landing. Step 3b moves everything else. The product
brief is [`docs/product/home.md`](../product/home.md).

## What is new under it

- `GET /api/me/home`, `/home/week` and `/home/friends`
  (`services/web-api/src/routes/home.mjs`): the app's internal API, not a JSON
  API version. One charge on the person's hourly bucket per request. Reads run
  one after another on the one client; `panel()` makes each fail alone.
- Clan's `GET /clans/<tag>/home` (`homeView`): `memberView` plus the open Actions
  this person can take, in `inActionOrder`. It never evaluates, raises or
  numbers: Actions' GET can, Home must not.
- `packages/tools/src/friends-week.mjs`: the mail's friends builder, moved so the
  web can call it. The mail's output is unchanged (`services/jobs` tests) and a
  web caller can pass `within()` to stop adding deck cards near its deadline.
- `packages/record/src/game-week.mjs`: `lastGameWeek` and friends, moved from the
  mail so a page can name the same week.
- `addPlayer({ follow })` and `relationship: "friend"` on `POST /api/claims`:
  Follow. It refuses with `no_own_player` when the account has no primary or alt,
  never sets a primary, and turns a watched claim into a friend.
- The shell (`apps/web/src/shell/Shell.jsx`) is only on `/home*`, and written so
  3b can wrap every page in `AppShell`.

## Defaults chosen in the build [engineering, 2026-11-05]

- Needs you lags Clan until the next evaluation, rather than making Home write.
- An unverified person gets no Action rows, since they cannot take them.
- A friend's name opens Explore's player page, because Ladder only reads your own
  players. A clanmate's opens their Clan member page.
- Trophies show on Trophy Road only; Path of Legends shows its net in recorded
  battles. Challenge and tournament battles get no chip.
- Step 4 of the new-account steps links to Verify instead of embedding the deck.
- `robots.txt` and the sitemap are left alone, as `/console` is.
- "That player is already yours." is new wording: no board draws that state.

## Promises the code could not keep

- Timeline's games in place read `when · mode · outcome`. The evidence route has
  no opponent or score, so the board's "Win 3-0 against ..." is not drawn.
- "and N more in Clan › Today" links to `/clan/<tag>/actions`, which is still
  called Actions until step 4.

## Infrastructure

Two CloudFront behaviours, `/home` and `/home/*` (20 of the default 25). No IAM
change and no migration.

  count, through one `openActionsFor`.
