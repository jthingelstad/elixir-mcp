# 2026-10-20 — The shared rail pass, and Console, Ladder and Clan fixes

A usability pass Jamie approved on 2026-10-20: the shared rail plus the
confirmed Console, Ladder and Clan bugs. No contract change: MCP 11.13.1
and JSON API 3.2.0.

- **Folded rail mark** (`packages/ui/src/Rail.tsx`). Narrow, with the
  list closed, the toggle row carries one mark for every other item with
  a dot or the new `attention` field. Its title and accessible name list
  each one ("Timeline: Unread notifications"). A plain `meta` count is
  not attention. Clan's Actions sets `attention` from `open_actions`.
- **Sticky rail.** Wide, the rail's contents sit in `.rail__pin`: sticky
  at the top of the window, at most the window less the top bar tall,
  and scrolling on its own. The foot sticks to the pin's lower edge, so
  Send feedback stays in reach on a rail taller than the window (a Clan
  leader's at 720px). Narrow is unchanged.
- **Console Send feedback** opens the kit's `FeedbackSheet` over the
  page, with the page key as context (area `console`), as Ladder and
  Clan do. The sheet gained `historyHref`, a link to Console ▸ Feedback
  on all three surfaces; the account menu still lists Feedback.
- **Clan rail groups.** Each item names its group, and the kit draws a
  heading where the group changes, so Scout sits under Manage for an
  elder with a policy (it fell under Social).
- **Clan `ELIXIR_LINKS`** are same-origin paths. Console paths go
  through the kit's `Link` (in-app); docs paths stay page loads.
- **Ladder modes.** Decks puts the address's mode first (its panel, or
  the table with that mode's rows first) and adds jump links; Days
  played leads each day and the key with the address's mode and quiets
  the rest. Order and emphasis only.
- **Copy.** Invite and the Ladder doc no longer say a deck is "judged".
- **Anchors.** Overview's Add your player goes to
  `tracking#add-player-tag`, and Tracking focuses the field from the
  router's hash (the window's hash lags an in-app move). The Actions
  Discord nudge opens Settings at `#discord`.

Defaults taken [engineering]:

- An alert beats unread in the folded mark. The mark leaves out the
  current page's item and goes while the list is open.
- The pin's height is the window less 61px (the top bar and its rule).
- The sheet's history link shows on all three surfaces, before and after
  filing.
- Only an address that names a mode leads (`askedMode`). The mode Ladder
  picks on its own changes nothing. On Days the emphasis applies only to
  a mode the season has.
- A Decks jump link for a table mode lands on that mode's first row, or
  on the table while it reads.
- `ELIXIR_LINKS.home` and `verifyDocs` have no reader; they were kept,
  same-origin.
- Only Overview's empty-state button carries `#add-player-tag`. Other
  links to Tracking keep landing at the top.
