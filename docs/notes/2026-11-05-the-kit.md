# 2026-11-05 — The kit, step 2 of the redesign

One page head, one table, one panel, one empty state, in the shared packages,
and today's pages moved onto them. No route, nav, rail or page content moved,
and no words changed. No migration; MCP and JSON API unchanged.

**What it is.** React parts in `packages/ui/src`, styles at the end of
`packages/design/src/components.css` under `kit-*`, using the existing tokens.
There is no second stylesheet and no second set of tokens.

- `PageHead`: h1, one sub line, a right-hand slot, a crumb above.
- `FreshChip`: "Battle log read 15 min ago" in a folded native `details`, with
  a plain explanation inside. Built, not placed yet: see below.
- `Tabs`: a real tablist of buttons or links, count badges, arrow keys, one
  tab stop, and it scrolls itself rather than the page. `wrap` wraps instead.
- `Chips` and `Chip`: a row with `aria-pressed`.
- `Panel`, `Rows`, `Row`: an optional head (title and a right-hand link); a
  titled section is a named region.
- `Table`: columns declared once, so head, cell and phone label cannot drift.
  Real `th` with `scope`, numbers right-aligned and tabular.
- `Empty` and `ErrorState`: title, one line, one action; the same shape when a
  read failed, with Try again only when something can retry.
- `Stats` and `Stat`: a row of labelled numbers.

**A table at phone width** (760px and under) never scrolls the page. `phone`
says how: `cards` (default) makes each row a block, its first column the title
and the rest label and value; `fit` keeps a few short columns and tightens;
`scroll` scrolls inside its own box and is for Admin only.

**Choices made for this step** [engineering, 2026-11-05]:

- The page title uses the display face at 28px (24px on a phone), as the boards
  draw it. It was Inter since the 2026-10-13 cleanup. Admin keeps the old head.
- Panels are filled surfaces now, and tables sit inside them, as on the boards.
  The old rule against that is gone from the stylesheet.
- Old class names stay alongside the kit's where tests or other pages read them
  (`page__title`, `page__lede`, `panel`, `empty`, `table`).
- `FreshChip` is not on a page. Its explanation is new words, and step 2 changes
  none; Ladder's scope bar in step 3 is where it lands.
- Ladder's mode switch and order links stay `nav` with `aria-current`; step 3
  rebuilds them.

**Left as they are.** Admin's head and its two hand-written tables; the battle
page's table (its layout is a standing ruling); Ladder's Form comparison grid,
which has its own stacked cells and phone rules; Home's panels and Console's
Overview, which step 3 replaces. Heads left: sign-in, the shell's own pages,
Explore's record head, the Clan refusal and verify pages and Member activity's
head (they are not the page-head shape). Empties left: Ladder's first read
(its body is a live status), and Explore's three lookup results.
