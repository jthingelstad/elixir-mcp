# Player and clan MCP connections

MCP 15.0.0 supports per-request discovery alongside legacy initialization.
Lists are private to the credential. The home-clan Timeline filters subjects
before building its items and entries. Migration 0308 gives each scoped
reader an independent position. The public directory supports exact lookup.
Personal connections receive a post-change hint and can read reaction counts
on their authored posts. The game record and battle-post aliases are intact.
JSON API 6.0.0.
