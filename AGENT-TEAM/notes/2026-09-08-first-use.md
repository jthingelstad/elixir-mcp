# First-use group: verification receipts

Jamie selected the first-use group after the answer-integrity fixes. The
implementation isolates the account read model and UI component; no migration
or MCP contract change is needed. The durable measurement decision is in
`docs/NOTES.md`, and product behavior is documented in the public quickstart.

## Local verification

- New API tests first failed with 404 for both authenticated and anonymous
  requests; the implemented route passes authentication, account isolation,
  capture evidence, time windows, expired/revoked connections, and audit filters.
- `npm run verify` passed: 515 tests (454 Node, 61 UI), format, lint and Knip.
- The permanent UI journey covers account overview -> add player -> waiting
  capture -> recorded profile -> copied question -> personal connections.
  Other cases cover sparse and old history, network failure/retry, clipboard
  refusal/manual copy and late responses after the primary player changes.
- `node infra/scripts/build-site.mjs --skip-stats` passed both builds and the
  merged-tree validation (35 files, 18 indexable pages plus the app shell).
- Browser plugin not available in this session's skill catalog; used the
  bundled Playwright runtime against the built app at
  `http://127.0.0.1:4328/account/overview`, with local HTTP fixtures and all
  external requests intercepted. No production analytics or member writes.
- Chromium at 1440x1000 and 390x844: correct page identity, meaningful content,
  no framework overlay, no app console errors, no mobile horizontal overflow.
  Exercised add -> capture pending, connection navigation, full-question
  disclosure, clipboard contents, failed request -> retry, and same-player
  Explore navigation. Inspected desktop and mobile screenshots in /tmp.

## Acceptance boundary

Scratch PostgreSQL verifies the read model and personal-session route. Browser
fixtures verify the rendered journey. Natural personal MCP use and user judgment
of answer usefulness remain the acceptance signal; test interactions are not
counted as member adoption. No client authorization or production user writes
are manufactured to establish that signal.
