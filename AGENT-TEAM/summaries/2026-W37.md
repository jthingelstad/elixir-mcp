## Ranked next improvements

1. **Approve additive deck comparison context.** Add `mean_level_gap` and a
   per-row mode mix to `battles_decks`, plus a conditional non-comparability
   note when returned rows materially differ. Keep `battles_levels` as the
   diagnostic tool. This directly closes #34 without inventing a verdict.
2. **Make evidence failure terminal in the preview.** When every supporting
   MCP call fails, the routine must publish the failure or skip, never a
   plausible comparison. This is a sibling-repo consumer guard; the server
   transport fix alone cannot enforce it.
3. **Isolate elixir-bot tests from the live MCP door.** Patch the attendance
   fixture's MCP call before it reaches invalid `#ABC123`; keep the local
   fallback assertion. This removes 38 misleading weekly errors without
   changing production behavior.
4. **Watch the remaining analytical tail before changing capacity.**
   `battles_levels` was still p95 8.9 seconds and max 22.2 seconds this week.
   The public record is healthy, with zero queued/dead jobs and 27 capture gaps
   in 5,632 audited polls (0.48%); measure another window before an RDS or
   materialization decision.
